隐私政策

更新日期：2026年10月7日。本工具仅供账户所有者本人使用。

数据访问与用途

通过 Gmail API 的 gmail.readonly 权限读取招聘订阅邮件。授权范围覆盖邮箱，应用通过发送方与查询规则限制实际处理范围。使用邮件正文、职位链接、来源标识和时间进行机会提取、去重、筛选和推荐。指定 Telegram 来源的数据用于同一用途。

存储与共享

授权凭据不发布在网站或代码仓库，不输出到聊天或日志。采集证据、候选职位、匹配依据和反馈保存在账户所有者控制的服务器。符合条件的机会摘要发送到所有者配置的 Telegram 目的地，Telegram 会处理这些消息。数据不用于广告、不出售、不用于训练通用人工智能模型。

控制与删除

账户所有者可以停止采集、删除本机和服务器的凭据及已保存的采集数据，并在 Google 账号第三方连接设置中撤销 Gmail 授权。撤销授权不会自动删除已保存的采集记录，需另行删除。

本工具对 Google API 数据的使用与传输遵守 Google API Services User Data Policy，包括 Limited Use 要求。
